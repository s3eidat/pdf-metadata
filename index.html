PDF Metadata

See what a PDF says about you before you send it: author, software, dates, edit history. Edit any of it, or strip it all in one click. The file never leaves this device.

    Why it matters
    
        
      
          
    • Author is often your full name or your computer's login name, filled in silently by Word, Pages or Acrobat.
      • 
          
    • Creator / Producer name the software and version you use.
      • 
          
    • Dates show when the file was really made and edited, including your time zone.
      • 
          
    • XMP can hold an edit history and IDs that link this file to earlier versions of it.
      • 
          
    • Custom fields can carry a company name, a template, or the original file path.
      • 
        
    
        
    Not covered: pictures inside the PDF can carry their own camera data (EXIF). This tool doesn't rewrite images.
